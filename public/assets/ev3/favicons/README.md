# FitCar Company favicon set

Optimized for small browser tab icons using the **F** letter extracted from the provided FitCar Company logo. The original dark purple (`#1D0840`) and white identity is retained.

## Files

- `favicon.ico`: 16, 32 and 48 px in one file
- `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png`: classic browser icons
- `favicon-96x96.png`: larger browser/shortcut icon
- `apple-touch-icon.png`: iPhone/iPad home screen icon at 180 px
- `favicon-180x180.png`, `favicon-192x192.png`, `favicon-512x512.png`: app/PWA sizes
- `site.webmanifest`: app icon and brand color metadata
- `head-example.html`: tags to copy into your website's `<head>`

Upload the files to your website's public root. Ensure `/favicon.ico` and the other referenced paths are accessible, then copy the head tags.

Keep `favicon-master.png` as a high-resolution working source if you want to export more sizes later.
